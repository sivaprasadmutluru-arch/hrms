# Careers and candidate application verification — 2 November 2026

Implemented public organization-specific careers listings and individual job links, with an anonymous application form, optional PDF resume, consent, duplicate-email protection, and a basic per-IP application rate limit/honeypot. Public requests derive organization and tenant schema from the URL rather than company headers or login context. Only active, published, open jobs within their application dates are exposed; suspended organizations are hidden.

HR can add candidates from Recruitment → Applicants, see submitted applications and candidate IDs, and download resumes through an authenticated company-scoped endpoint. Resume files are stored outside public media, with private filesystem permissions. No login account or employee record is created by applying. Existing candidate names now render in onboarding and pipeline views. New posts initialize Applied, Screening, Interview, and Offer stages. Job forms now send backend-compatible fields, support drafts/closing, and expose careers/job links.
